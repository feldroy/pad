## Build & Run Commands

- **Install dependencies**: `uv sync`
- **Run the CLI**: `uv run pad-app`
- **Build package**: `uv build`

## Project Overview

pad-app is a Python CLI application using `uv` as the build system and package manager. Requires Python 3.14+.

Entry point: `src/pad/__init__.py:main()`

## Running the app

```sh
pad
```
